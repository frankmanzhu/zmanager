# ZManager CLI 2.1.0 Release Notes

ZManager CLI 2.1.0 is a major milestone release that transitions ZManager to a fully native, pure-Rust archive engine, introduces dual artifact profiles (full vs. offline), expands native format support to ISO, CAB, CPIO, AR, XAR, LHA, WARC, MTREE, RPM, DEB, MSI, and virtual disk images, adds retained archive sessions, and significantly expands test coverage and cross-platform reliability.

## Highlights

### 🦀 Pure-Rust Archive Engine & Libarchive Removal
- **Zero C-libarchive Dependency**: Completely removed `zmanager-libarchive` and `libarchive-3.8.9` C sources from the workspace. All archive format handling is now performed by pure-Rust native adapters and bundled memory-safe components.
- **Unified Engine Architecture**: All extraction, listing, testing, and creation workflows across the CLI, FFI, and tests now route through a centralized engine adapter and session registry (`zmanager-core::engine`).
- **Retained Archive Sessions**: Added low-overhead retained archive sessions (`retain_session`, `extract_selected`, `test_selected`, `copy_selected`) for high-performance browsing and repeated selected extractions without re-parsing archive headers.

### 📦 Expanded Native Format Adapters
- **Disk Images & Forensics**: Native support for ISO 9660 (`.iso`), UDF (`.udf`), Microsoft Virtual PC / Hyper-V (`.vhd`), VMware virtual disks (`.vmdk`), and Apple Disk Images (`.dmg`), including MBR/GPT partition resolution and inner filesystem extraction (NTFS, FAT/exFAT, ext4, UDF) via `forensic-vfs-engine`.
- **System & Package Formats**: Native nested Debian package (`.deb`) control/data extraction, Red Hat Package Manager (`.rpm`) header parsing with CPIO payload extraction, Windows Installer (`.msi`), Apple Installer (`.pkg`), and Unix Archive (`.a`, `.ar`, `.lib`).
- **Extended Archive Formats**: Native Windows Cabinet (`.cab`), CPIO (`.cpio`, `.cpgz`, and compressed variants), LHA/LZH (`.lha`, `.lzh`), XAR (`.xar`), WARC (`.warc`), and MTREE (`.mtree`) manifests.
- **Pure-Rust Stream Decoders**: Native pure-Rust LZO1X (`.lzo`, `.tar.lzo`) and Unix compress (`.Z`, `.tar.Z`) stream decompression; explicit rejection of obsolete/insecure algorithms (`lrzip`, `grzip`).
- **Split & Multi-volume Archives**: Added support for numbered ZIP volume sets (`.z01`...`.zip`), split RAR5 multi-volume archives, and numbered 7z volumes (`.7z.001`).

### 🛡️ Dual Product Profiles (Full vs. Offline)
- **Hosted Feature Boundary**: Extracted online TZAP account and identity transport into a dedicated positive Cargo feature (`tzap-online`) and separate crate (`zmanager-tzap-hosted`).
- **Offline Binaries**: Releases now ship dual artifacts for every target platform:
  - **`zm` (Full)**: Complete CLI with online identity, hosted authentication, certificate inventory, and document sharing (`zm auth`).
  - **`zm-offline`**: Zero-network binary with all network and HTTP client dependencies eliminated from the build graph for air-gapped systems and minimal deployments.
- **Dedicated Package Formulas**: Homebrew (`zmanager` and `zmanager-offline`) and WinGet manifests (`TzapOrg.ZManagerCLI` and `TzapOrg.ZManagerCLI.Offline`).

### 🍎 Cross-Platform Capability Registry & Apple Archive
- **Compile-Time Capability Registry**: Replaced scattered platform `#cfg` gates with a unified compile-time table (`FORMAT_CAPABILITIES`), ensuring identical API signatures and truthful capability reporting across all operating systems.
- **Un-gated Apple Archive Surface**: Apple Archive (`.aar` / `.aea`) format definitions and error types are portable across all platforms, returning structured unsupported errors off-Apple while enabling native framework acceleration on macOS and iOS.
- **Cross-Tool Apple Verification**: Added comprehensive cross-tool verification test suites comparing extraction shape, metadata, and symlinks against macOS `hdiutil`, `pkgutil`, and `ditto`.

### ⚡ Safety, Usability & Test Hardening
- **Path & Selection Normalization**: Unified backslash `\` handling for Windows paths in entry selection and pattern matching. Added support for directory pattern matching (`folder`, `folder/`, `folder\`).
- **Combinatorial Extraction Matrix**: Added an extensive integration test suite (`combinatorial_extraction.rs`) testing 1,126+ permutations of formats, compression levels, password encryption, cryptographic signatures, recovery levels, and selection paths. Workspace test coverage expanded to 1,700+ tests.
- **Extraction Hardening**: Solid 7z uncompressed size tracking, multipart archive listing deduplication, and atomic temporary preview replacements.
- **CLI Options**: Added `--exclude-sidecar` flag for filtering platform metadata sidecars during archive operations.

## Installation

### macOS (Homebrew)
```sh
# Full build
brew install tzap-org/zmanager/zmanager

# Offline build (no network features)
brew install tzap-org/zmanager/zmanager-offline
```

### Linux (Install Script)
```sh
# Full build
curl -fsSL https://raw.githubusercontent.com/tzap-org/zmanager/main/install.sh | sh

# Offline build
curl -fsSL https://raw.githubusercontent.com/tzap-org/zmanager/main/install.sh | sh -s -- --offline
```

### Windows (WinGet)
```powershell
# Full build
winget install TzapOrg.ZManagerCLI

# Offline build
winget install TzapOrg.ZManagerCLI.Offline
```

## Known Backend Limits

- **Creation Scope**: Archive creation is focused on modern, safe formats: `.zip` (with AES-256), `.tzst` (`.tar.zst`), `.tgz` (`.tar.gz`), `.tzap`, `.7z` (with AES-256), and `.aar`/`.aea` (Apple Archive).
- **Apple Archive Platform Scope**: Reading and creating Apple Archives (`.aar` and `.aea`) is supported on macOS and iOS.
- **In-Place Modification**: In-place modification of existing archives is intentionally unsupported; extract, modify, and create a new archive.
- **RAR Creation**: RAR archive creation is not supported; RAR4 and RAR5 extraction is supported via the bundled UnRAR engine.
- **Raw Compression Streams**: Single-file compressed streams (`.gz`, `.bz2`, `.xz`, `.zst`, `.lz4`, `.lzo`, `.Z`, `.br`) extract to a single target file.
